# Pear Music Widget

A floating now-playing widget and menu-bar player for macOS. It connects to the
**API Server** plugin in [pear-desktop](https://github.com/pear-devs/pear-desktop)
or [th-ch/youtube-music](https://github.com/th-ch/youtube-music) and receives
player updates over WebSocket.

![The Classic skin on the desktop](docs/classic.png)

## What it does

Pear Music Widget provides two views of the same player:

- **Menu-bar dropdown:** click the menu-bar icon for artwork, transport controls,
  progress, queue, lyrics, and search. It closes on click-away or Escape.
- **Floating widget:** a resizable, always-available player that can sit anywhere
  on the desktop.

Menu-bar gestures:

| Gesture | Action |
| --- | --- |
| Left click | Toggle the dropdown |
| Double click | Show the floating widget |
| Right click | Open settings |

A solid menu-bar icon means connected; a hollow one means YouTube Music or its
API server is unavailable. Pressing play can launch YouTube Music. Double-click
the floating card—or the cover in the dropdown—to bring YouTube Music forward.

The floating widget's close button appears on hover and hides the widget. Use a
tray double-click or **Show floating widget** to bring it back.

## Skins

| Skin | Natural size | Layout |
| --- | --- | --- |
| **Classic** | 300×110 | Artwork on the left; titles and transport on the right |
| **Stack** | 330×284 | Artwork and titles above transport, progress, and an inline queue |

The widget and dropdown can use different skins. Resizing scales the chosen
layout without reflowing it.

## Controls

The corner bar contains **Repeat**, **Queue**, **Lyrics**, and **Search**. Each
button can be hidden per skin, and the bar can hide when idle.

- **Queue:** opens the full playlist. Click any row, including a previously
  played track, to jump to it. Stack also shows a horizontal six-track strip.
- **Lyrics:** shows synced rolling lyrics when available. Click the middle of a
  line to seek or scroll to browse manually. Lyrics timing can be adjusted by up
  to two seconds, traditional Chinese can be converted to simplified Chinese,
  and offline numberless Jyutping can be shown beneath Chinese lines. These
  controls are grouped under the **Lyrics** submenu.
- **Search:** use the pointer or ↑/↓ and Enter to play a result after the current
  track.
- **Volume:** drag the speaker popover, scroll over the card, or press ↑/↓ while
  focused. Hold Shift for 1% keyboard steps.

Other features include play/pause, next, previous, shuffle, like/dislike,
repeat-all/repeat-one, seeking, cover-derived tint, opacity, light/dark
appearance, always-on-top mode, remembered positions and sizes, native macOS
vibrancy, and no Dock icon.

Lyrics are tried from YouTube Music first and [LRCLib](https://lrclib.net) as a
fallback. This is the widget's only non-localhost network access. Results are
cached under `~/Library/Caches/pear-music-widget/lyrics`; the menu controls the
cache size and can open or clear it.

## Install

1. Download the DMG from the
   [latest release](https://github.com/TianCal/pear-music-widget/releases/latest).
2. Drag the app to Applications.
3. Enable the **API Server** plugin in YouTube Music.
4. Launch the widget and approve its access-token request in YouTube Music.

The app is ad-hoc signed but not notarised. If macOS blocks the first launch,
right-click the app and choose **Open**, or run:

```bash
xattr -dr com.apple.quarantine "/Applications/Pear Music Widget.app"
```

Requires Apple Silicon. Built and tested on macOS 26.

## Run from source

Install a [Rust toolchain](https://rustup.rs) and the Xcode command line tools.
There is no npm or bundler step.

```bash
cargo run --manifest-path src-tauri/Cargo.toml
cargo run --manifest-path src-tauri/Cargo.toml -- --doctor  # check connectivity
./scripts/reinstall-local.sh                               # rebuild and reinstall
```

To build a DMG, install `tauri-cli`, then run `cd src-tauri && cargo tauri build`.

Publishing requires an authenticated GitHub CLI and a clean, current `main`:

```bash
./scripts/publish-release.sh small  # patch
./scripts/publish-release.sh minor
./scripts/publish-release.sh major
```

## Compatibility and data

The app targets API Server `/api/v1` at `http://127.0.0.1:26538`, verified
against YouTube Music 3.12.0. Run `--doctor` if the widget remains on its setup
screen.

Settings are stored in
`~/Library/Application Support/pear-music-widget/settings.json`. Quit the app
before editing it. Unknown keys are preserved.

Transport icons are hand-authored SVG paths in [src/index.html](src/index.html),
and app/menu-bar icons are generated by [src-tauri/build.rs](src-tauri/build.rs).
Bundled Cantonese pronunciation data and its licenses are documented in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
See [AGENTS.md](AGENTS.md) before changing the event payloads, volume path,
window geometry, or tray behaviour.
