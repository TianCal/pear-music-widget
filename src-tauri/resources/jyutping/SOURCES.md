# Data sources

The binary dictionaries in this directory come from `canto-hk-g2p` 2.6.1,
generated by its `scripts/fetch_data.py` and `scripts/build_dict.py` tooling.

## rime-cantonese

- Commit: `ec6ee73e8313` (2026-03-07)
- License: CC-BY-4.0
- Repository: https://github.com/rime/rime-cantonese
- Included inputs: `jyut6ping3.chars.dict.yaml`,
  `jyut6ping3.words.dict.yaml`, and `jyut6ping3.lettered.dict.yaml`
- The ODbL-licensed `jyut6ping3.maps` data is not included.

## Unicode Unihan Database

- Field: `kCantonese`
- License: Unicode License v3
- Source: https://unicode.org/charts/unihan.html

## ToJyutping

- Version: 3.2.0
- License: BSD-2-Clause
- Repository: https://github.com/CanCLID/ToJyutping
- Used by the upstream build process to choose the primary reading for
  ambiguous entries; its code and data are not bundled here.

## canto-hk-g2p hand-curated data

- HK colloquial readings, separable words, romanized slang, and classifier
  tone changes
- License: Apache-2.0
